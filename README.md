# Smart Home Energy Monitor

A Python-based desktop application designed to simulate household electricity consumption, monitor energy usage, estimate electricity costs, and provide insights into improving energy efficiency.

## Project Overview

The Smart Home Energy Monitor is a graphical application developed using Python and Tkinter. It provides an interactive environment for exploring household energy consumption and understanding how different appliances contribute to overall electricity usage.

The application combines energy calculations, simulated monitoring, appliance management, and data reporting in one interface.

## Key Features

- **Energy Dashboard:** Displays household electricity consumption and estimated energy costs.
- **Appliance Management:** Add, edit, and remove household appliances and configure their power ratings and usage hours.
- **Energy Monitoring:** Simulates electrical readings such as power, voltage, and current.
- **City Monitor:** Provides simulated energy readings for selected cities in Nepal, including Kathmandu, Pokhara, Lalitpur, Biratnagar, and Chitwan.
- **Smart Suggestions:** Provides recommendations based on appliance usage and estimated energy consumption.
- **Reports and Data Export:** Generates energy reports and exports data in CSV format.

## Technologies Used

- Python
- Tkinter (Graphical User Interface)
- CSV module
- Random and Math modules
- Date and Time utilities

## How to Run

### Requirements
- Python 3 installed
- Tkinter support

### Run from Source

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python dashboard.py
```

Alternatively, Windows users can launch the provided `.exe` application directly.

## Important Note

This project uses simulated electrical readings and city-level energy data. It does not currently connect to physical electricity meters, IoT devices, or external city electricity-grid monitoring systems.

Energy consumption and cost estimates are calculated using configured appliance power ratings, usage durations, and electricity tariff values.
